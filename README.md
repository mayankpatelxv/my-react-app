# bizBuddy - Business Management Application

🔗 **Live Site:** [https://mayankpatelxv.github.io/my-react-app/](https://mayankpatelxv.github.io/my-react-app/)

## About

bizBuddy is a complete business management application designed for small and medium businesses.

## Features

- 🛒 Sales & Invoice Management
- 📦 Purchase & Expense Tracking
- 📋 Inventory Management
- 👥 Customer & Supplier Management
- 📈 Annual Financial Reports
- 📊 Dashboard with Business Metrics
- 🤖 AI-Powered Chatbot Assistant
- 📱 Progressive Web App (PWA)
- 🔐 Secure Authentication (Email & Google)

## Tech Stack

- React.js
- Supabase (Database & Auth)
- Google Gemini AI
- CSS3

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Configure environment variables in `.env.local`
4. Run development server: `npm start`
5. Build for production: `npm run build`
