# PDF Invoice Generation Feature

## Overview
The Sales component now includes professional PDF invoice generation and printing capabilities using the jsPDF library.

## Features

### 📄 Download PDF Invoice
- Click "Download PDF" button to generate and download a professional invoice
- Automatically generates unique invoice numbers (INV-XXXXXX format)
- Includes company branding (bizBuddy logo and colors)
- Professional layout with customer information, itemized list, and totals

### 🖨️ Print Invoice
- Click "Print Invoice" button to open PDF in new window with print dialog
- Same professional formatting as download version
- Optimized for standard paper sizes

## PDF Content Includes

### Header Section
- **Company Name**: bizBuddy with brand colors
- **Company Tagline**: "Business Management Solution"
- **Invoice Title**: Professional "INVOICE" heading
- **Invoice Details**: Number, date, and due date

### Customer Information
- **Bill To**: Customer name from selected party
- Clean, professional formatting

### Itemized Table
- **Columns**: Item name, Quantity, Unit Price, Line Total
- **Styling**: Alternating row colors for readability
- **Brand Colors**: Header with bizBuddy brand colors

### Totals Section
- **Subtotal**: Sum of all line items
- **Discount**: If applicable (shown when > 0)
- **Tax**: Calculated based on tax rate with percentage display
- **Grand Total**: Highlighted in brand colors

### Footer
- **Thank you message**: Professional closing
- **Generated by**: bizBuddy attribution

## Technical Details

### Library Used
- **jsPDF**: Lightweight PDF generation library
- **Size**: ~131KB added to bundle (acceptable for functionality)

### File Naming Convention
- Format: `Invoice_[NUMBER]_[CUSTOMER_NAME].pdf`
- Example: `Invoice_INV-123456_Acme_Corp.pdf`
- Special characters in customer names are replaced with underscores

### Validation
- **Customer Required**: Must select a customer before generating PDF
- **Items Required**: Must have at least one item with quantity > 0
- **Error Handling**: User-friendly error messages for validation failures

## Usage Instructions

1. **Create Invoice**: Add customer and items to your invoice
2. **Download**: Click "Download PDF" to save invoice to your device
3. **Print**: Click "Print Invoice" to open print dialog
4. **File Location**: Downloaded PDFs go to your default Downloads folder

## Browser Compatibility
- ✅ Chrome, Firefox, Safari, Edge
- ✅ Mobile browsers (Android/iOS)
- ✅ Works offline (no internet required for PDF generation)
